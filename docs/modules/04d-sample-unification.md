# Phase 4D：统一样例数据与诚实展示

本地验证：2026-09-12。无新增依赖；无部署。

## 做了什么

- 后端comparison、compare路由及schemas：去掉随机真实品牌／平台Mock，复用18条固定虚构样例，精确过滤不自动放宽，带价格区间和证据。官方渠道无证据返回空；无评分不伪造排名。
- report服务／路由：按目录ID查事实，忽略客户端任意名称、价格、候选；报告是知识摘要，不冒充个性化最优排序。
- trend服务／路由：删除随机90天价格及购买时机建议，所有ID明确无历史数据。suggest服务／路由改确定性导航；prompt_engine删除不再调用的三个Prompt。
- Flutter product模型／卡片、compare/result/trend/report页面、api_service：展示区间与证据，移除销量／好评排序和虚假承诺，用户点击才能撤销筛选；并发列表加载版本校验防止旧请求覆盖新条件。空识别品牌／颜色不作为查询条件。旧报告不把客户端数据渲染为已核验事实。
- README、API、架构及模块索引同步更新。保留API路径及主要导航，新工作流报告不受影响。

## 兼容与风险

rating、created_at现在可空；依赖假评分／随机价格的旧调用者需升级。旧reportData不再渲染为有据事实，缺少有效ID需重新选择样例。真实识别品牌通常不在虚构库中，严格筛选为空是预期，只有用户主动点击才移除条件。
未验证真机布局、真实模型、Docker运行；本地单用户／单worker边界不变。旧自然语言filter仍为兼容模型解析入口，正式购物链路使用结构化需求解析与事实过滤，不依赖它。
